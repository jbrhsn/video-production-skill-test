# Production routing

Use the route request artifact with `recordedMedia`, `generatedNarration`, `needsExplanation`, and `autonomy` to select one route. The router makes a deterministic first decision; it does not evaluate factual quality, rights, performance, or the usefulness of a visual explanation.

`recordedMedia` means footage or recorded audio carries a material part of the output. `needsExplanation` means the editorial plan already identifies an idea that the source alone cannot explain clearly. A yes value selects editorial treatment; it does not authorize a takeover at an arbitrary moment.

The chosen route becomes project evidence. Re-route when the source role or editorial goal materially changes, then re-plan affected assets, timeline, visual events, and review scope.
