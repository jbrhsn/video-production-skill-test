# Style system

A style profile is a production grammar. Resolve one before authoring scenes so its editorial, visual, motion, caption, sound, and QC rules reach the same implementation.

The supplied profile catalog is a starter library. Compose a project by selecting a base profile, applying brand tokens and prohibitions, then applying specific project overrides. The resolver records the origin of every resolved field and produces a digest. Keep the resolved artifact as the design authority; generated TypeScript tokens are derived output.

Use profile guidance to make informed choices, not to impose cut counts or promise retention. A calm documentary may retain a meaningful pause; a social profile may use short beats when the idea benefits from them.
