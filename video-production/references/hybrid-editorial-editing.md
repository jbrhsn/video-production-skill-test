# Hybrid editorial editing

Use hybrid editorial editing when recorded speech makes a claim that needs a map, chart, document, system diagram, comparison, historical sequence, or other explanation the source does not show.

Keep the presenter visible when expression, trust, reaction, or personal credibility carries the meaning. Select overlay, split, picture-in-picture, or full-screen explanation based on which element owns the information. A takeover needs a dialogue occurrence and a fixed duration on the master clock. If it needs more time, propose an explicit edit or hold; never extend speech silently.

Inspect source-to-explanation and explanation-to-source playback windows. Check that dialogue mounts once, captions remain on the dialogue clock, and the return lands at the declared source occurrence and PTS.
