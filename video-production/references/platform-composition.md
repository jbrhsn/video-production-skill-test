# Platform-aware composition

Read when choosing platform, aspect ratio, or adapting a project. Platform is a creative input, not only an export size.

The scaffold's `--profile youtube-horizontal` selects 1920 × 1080; `--profile vertical` selects 1080 × 1920. Explicit width/height override profile dimensions. These are production defaults, not statements of platform upload limits. Duration follows the requested scope and measured script; a horizontal explainer need not be long and a vertical video need not be frantic.

For horizontal YouTube, use the width to explain spatial relationships: side-by-side comparisons, persistent diagrams, paths, overview/detail moves, and cause/effect staging. For longer videos, plan chapter questions and intermediate payoffs; keep orientation between chapters. Align the opening with the title/thumbnail promise when those assets are provided. Do not simply stretch portrait cards across a landscape canvas.

For TikTok, Instagram Reels, and Shorts, design narrower visual groupings and readable focal points around interface occlusion. Get to the idea promptly; show one complete argument rather than a rushed catalog. Re-stage comparisons vertically if needed. Preserve enough hold time to read a completed relationship. A loop is optional and must not undermine the final payoff.

Adapt shared semantic content to each composition. Reflow text, re-stage diagrams, change shot scale, and recrop media around the subject. If a shorter version cannot preserve the argument, write a separate short-form script. Do not crop a finished landscape master and assume the resulting vertical version is ready.

The generated `SafeAreaReview` composition uses adjustable inset fractions from the edit plan. Defaults are conservative design guides, not current platform guarantees. Before delivery, consult official placement guidance and note the date and relevant placement in scene-design.md; ad UI may differ from organic UI and from another platform. [TikTok creative guidance](https://ads.tiktok.com/business/en/blog/creative-best-practices-top-performing-ads?redirected=1) supports vertical, UI-aware design but does not establish organic reach. Fetch Instagram/YouTube guidance for the actual target rather than copying TikTok measurements.

Inspect each requested aspect ratio at its intended viewing size. Check caption bounds, long words, chart labels, focal objects, and transitions under UI overlays. Use layout measurements where practical; character counts are only a caption grouping heuristic. Keep original code illustration and motion graphics available when local media does not fit.
