# Visual and motion QC

Machine QC reports only measured findings. Each report records check coverage, rule IDs, severity, master ranges, evidence, and detector version. A detector error or unavailable detector is not a pass.

Current timeline QC verifies master and caption bounds plus overlap policy. Future layout checks must use actual post-font bounds and output-coordinate transforms. Frame-difference scans can flag a stalled or black/flash range, but must account for declared holds and intentional dark shots. Instrumented event markers and image changes support an event check; neither proves the event communicated its intended meaning.

Review continuous playback for timing, motion, lip sync, intelligibility, and pacing. Use stills and contact sheets for composition and coverage only.
